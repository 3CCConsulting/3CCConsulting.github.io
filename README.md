- 🤝 **Fractional Process Support** — ongoing help as you scale

## Structure

This is a single-page static site — `index.html` contains all HTML, CSS, and JavaScript. No build step, no dependencies, no framework overhead.

## Local Preview

\```bash
python3 -m http.server
\```

Then open `http://localhost:8000` in your browser.

## Deployment

Published via **GitHub Pages** from the `main` branch. Any change committed to `index.html` on `main` goes live within a few minutes.
